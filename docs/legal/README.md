# Huquqiy hujjatlar

`PRIVACY_DRAFT.md`, `TERMS_DRAFT.md` — **qoralamalar**: kod nima qilishini aniq aks ettiradi, lekin huquqiy xulosa emas. Advokatga topshirish uchun tayyor. Ochiq huquqiy savollar (`OPEN_QUESTIONS.md`): 16 yosh va ota-ona roziligi, ma'lumotlarni O'zbekistonda saqlash, shaxsiy ma'lumotlar operatori sifatida ro'yxatdan o'tish.

Hujjatlar tasdiqlangach: ilovada kirishda «Roziman» belgisi va havolalar qo'shiladi (hozir yo'q — tasdiqlangan matn kerak).
